# 00 — Start here

1. Install a C compiler (GCC/MinGW on Windows, or Clang/GCC on macOS/Linux).
2. Check the compiler with `gcc --version`.
3. Setup the VS code Snippet for Boilerplate.
4. Compile `hello_world.c`.
5. Read the code from top to bottom: header, `main`, statements, return.
6. Change the output text and run it again.

A C source file normally uses the `.c` extension. The compiler translates it into an executable program.
