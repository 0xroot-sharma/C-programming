# Practice problems

Try solving these yourself before looking up solutions. Add your own `.c` files in the matching chapter folders.

## Fundamentals and I/O
- Convert Celsius to Fahrenheit.
- Calculate simple interest.
- Read a character and print its integer code.
- Swap two numbers (first with a temporary variable, then using a function and pointers).

## Operators and decisions
- Check whether a year is a leap year.
- Find the greatest of three numbers.
- Build a menu-driven calculator using `switch`.
- Check whether a character is a vowel or consonant.

## Loops
- Print a multiplication table.
- Find the sum of digits.
- Reverse a number and check palindrome.
- Check prime/composite.
- Print Fibonacci terms.
- Print left, right, and full pyramids.

## Functions and recursion
- Find factorial using both loop and recursion.
- Find GCD of two integers.
- Find power using recursion.

## Arrays and strings
- Find maximum and minimum in an array.
- Search for an element using linear search.
- Sort an array using bubble sort.
- Add and multiply two matrices.
- Count vowels, digits, spaces, and words in a line.
- Check whether a string is a palindrome.

## Pointers, structures, and files
- Swap two numbers using pointers.
- Store and display details of five students using an array of structures.
- Demonstrate the difference between `struct` and `union`.
- Save and read records from a file.
