# 01 — Fundamentals

C is a compiled, statically typed, general-purpose programming language. A variable must be declared with a type before it is used. An identifier is a name given to a variable, function, etc.

Identifier reminders:
- Start with a letter or underscore.
- Later characters may include letters, digits, and underscores.
- No spaces or other punctuation.
- C is case-sensitive.
- Do not use a reserved keyword as an identifier.

The exact size of a type is implementation-dependent. Use `sizeof` to inspect it on your compiler rather than assuming every platform has identical sizes.
